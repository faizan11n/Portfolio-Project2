About

I am a fresher DevOps engineer who learns by building. I set up my own EC2 servers, wrote Dockerfiles for many kinds of apps, built a Jenkins pipeline that ships containers to Docker Hub, and provisioned servers with Terraform and configured them with Ansible.

I like fixing real problems: when my Jenkins container said docker: not found, I traced it to the missing Docker CLI behind a mounted socket, and fixed it. I write down what broke and why, so the next build is calmer.
